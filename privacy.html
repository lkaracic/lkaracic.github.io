Privacy policy

Applies to the personal backup tool described on the home page.

Who uses it

Only the owner of this site. There are no other users.

What Google data it accesses

The tool requests only the Google Drive scope drive.file. This lets it see and manage only the files that the tool itself created in the owner's own Google Drive. It cannot see any other files.

What it does with that data

It uploads the owner's backup files (encrypted on the owner's computer before upload), lists them, and restores them when needed. Nothing else.

Collection and sharing

The tool does not collect, store, sell or share any personal data with anyone. No analytics, no advertising, no third parties. Access tokens are stored only on the owner's own computer.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
